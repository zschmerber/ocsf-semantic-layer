🎯 Query Examples

Example 1: Find Blocked DNS Queries

-- Semantic layer query (analyst-friendly)
SELECT 
    query_hostname,
    source_ip,
    cloud_region,
    event_time
FROM v_dns_event
WHERE action = 'Blocked'
  AND event_time >= CURRENT_DATE - INTERVAL 7 DAYS
ORDER BY event_time DESC;

Example 2: NXDOMAIN Rate (DGA Detection)

-- Pre-built metric for threat detection
SELECT 
    source_ip,
    COUNT(*) as total_queries,
    SUM(CASE WHEN response_code = 'NXDOMAIN' THEN 1 ELSE 0 END) as nxdomain_count,
    AVG(CASE WHEN response_code = 'NXDOMAIN' THEN 1.0 ELSE 0.0 END) as nxdomain_rate
FROM v_dns_event
WHERE event_time >= CURRENT_DATE - INTERVAL 1 DAYS
GROUP BY source_ip
HAVING nxdomain_rate > 0.3  -- High rate indicates DGA
ORDER BY nxdomain_rate DESC;

Example 3: Threat Intel Matching (Hot Path)

-- Fast IOC matching using observables table
SELECT 
    o.value as malicious_domain,
    ti.threat_type,
    ti.confidence,
    e.source_ip,
    e.event_time
FROM ocsf_observables o
INNER JOIN threat_intel_domains ti 
    ON o.value = ti.domain
INNER JOIN v_dns_event e 
    ON o.event_uid = e.metadata_uid
WHERE o.type_id = 1  -- Hostname
  AND o.event_time >= CURRENT_DATE - INTERVAL 1 DAYS
ORDER BY ti.confidence DESC;

💡 Key Benefits of Delta Lake Architecture

For Analysts: Query using business terms without knowing OCSF schema structure

For Engineers: Fully structured Delta tables, no JSON parsing overhead, ACID transactions

For Threat Hunters: Fast IOC matching with ZORDER optimization, time travel for investigations

For Data Quality: Schema enforcement, validation rules, deduplication in Silver layer
