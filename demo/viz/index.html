🔷 OCSF Semantic Layer

A semantic abstraction layer for the Open Cybersecurity Schema Framework (OCSF) that bridges physical schema and business-level security concepts. Auto-generate semantic models from compiled OCSF schemas, with visual representation and intelligent mapping assistance.

🎯 What is This?

The OCSF Semantic Layer provides a business-friendly abstraction over the complex OCSF JSON schema. Instead of querying raw event classes and nested attributes, security analysts can work with intuitive concepts like "Authentication Events" and "Failed Login Rate".

📊 Semantic Entities

Define business-level concepts (DNS Event, User, Device) that map to OCSF event classes with friendly attribute names like query_hostname and source_ip.

📈 Metrics & Dimensions

Create reusable KPIs like dns_query_count and blocked_dns_rate with dimensions for consistent security analytics across teams.

🔥 Hot/Cold Path Analytics

Optimized query paths: fast observables table for threat intel matching on hostnames/IPs, full events for detailed DNS investigation.

🏭 Warehouse Generation

Auto-generate dbt models, Cube.js schemas, SQL views, and ETL pipelines for Snowflake, Databricks, BigQuery.

📝 Semantic Model Example

Here's how you define a semantic entity that maps to OCSF DNS Activity events (class 4003):

entities:
  - name: dns_event
    caption: DNS Event
    description: DNS queries and responses
    source_event_classes:
      - 4003  # OCSF DNS Activity class
    attributes:
      - name: query_hostname
        caption: Query Hostname
        type: string
        ocsf_mapping:
          field: query.hostname
        is_dimension: true
      - name: source_ip
        caption: Source IP
        type: string
        ocsf_mapping:
          field: src_endpoint.ip
        is_dimension: true
      - name: action
        caption: Action
        type: string
        ocsf_mapping:
          field: action
        is_dimension: true

metrics:
  - name: dns_query_count
    caption: DNS Query Count
    aggregation: count
    measure:
      field: metadata.uid
    dimensions: [query_hostname, source_ip, action]

  - name: blocked_dns_rate
    caption: Blocked DNS Rate
    aggregation: avg
    measure:
      expression: "CASE WHEN action != 'Allowed' THEN 1.0 ELSE 0.0 END"
    dimensions: [source_ip]

🔄 Schema-Driven Generation

Instead of manually defining semantic models, you can auto-generate them from the compiled OCSF schema. The system intelligently extracts:

📦 Object Entities

High-usage OCSF objects (user, device, actor, file, process) become reusable semantic entities with all their attributes.

📋 Class Entities

OCSF event classes (authentication, file_activity) become event entities with flattened nested attributes and proper path mappings.

🎯 Inferred Dimensions

Enum attributes become categorical dimensions. Required/primary attributes become high-priority dimensions. Timestamps become time dimensions.

📈 Suggested Metrics

Count metrics for all events. Duration/size metrics when applicable. Success rate from status_id. Severity distribution from severity_id.

# Generate semantic model from compiled OCSF schema
ocsf-cli generate-from-schema \
    --schema ./schema/ocsf-compiled-v1.6.0.json \
    --output ./generated-model.yaml \
    --include-metrics

# Filter by category or class
ocsf-cli generate-from-schema \
    --schema ./schema/ocsf-compiled-v1.6.0.json \
    --output ./iam-model.yaml \
    --categories iam \
    --include-metrics

⚡ CLI Commands

# Initialize a new semantic model
ocsf-cli init -o semantic-model.yaml -n "my-model"

# Generate semantic model from compiled OCSF schema
ocsf-cli generate-from-schema -s schema.json -o model.yaml --include-metrics

# Validate model against OCSF schema
ocsf-cli validate -m semantic-model.yaml -s ./schema --json

# Generate warehouse artifacts
ocsf-cli generate -m semantic-model.yaml -o ./output -d snowflake

# Visualize the semantic layer
ocsf-cli visualize -m semantic-model.yaml -o graph.json -f json

# Translate a semantic query to SQL
ocsf-cli query -m semantic-model.yaml '{"entity":"dns_event","select":["source_ip"]}'
