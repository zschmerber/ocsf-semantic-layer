📊 Security Metrics

Pre-built metrics for DNS threat detection and analytics.

dns_query_count

Total number of DNS queries

COUNT(metadata.uid)

Dimensions: query_hostname, source_ip, action
Time Granularities: hour, day

blocked_dns_rate

Percentage of blocked DNS queries

AVG(CASE WHEN action != 'Allowed' THEN 1.0 ELSE 0.0 END)

Dimensions: source_ip, cloud_region
Time Granularities: hour, day

dns_by_severity

Count of DNS events grouped by severity

COUNT(metadata.uid)

Dimensions: severity, action
Time Granularities: hour, day

nxdomain_rate

Percentage of DNS queries resulting in NXDOMAIN (potential DGA indicator)

AVG(CASE WHEN response_code = 'NXDOMAIN' THEN 1.0 ELSE 0.0 END)

Dimensions: source_ip, cloud_region
Time Granularities: hour, day
Security Use Case: DGA detection - high NXDOMAIN rates indicate domain generation algorithm activity

🔥 Hot/Cold Path Architecture

Hot Path (dns_observables table): Fast lookup table containing extracted hostnames and IP addresses for rapid threat intelligence matching. Optimized for high-speed IOC queries.

Cold Path (full DNS events): Complete DNS event records with all attributes for detailed investigation and forensic analysis. Used when hot path identifies a match.

💡 Usage Examples

Natural Language Query: "Show me blocked domains from suspicious sources"

Translates to: SELECT query_hostname, source_ip, action FROM dns_event WHERE action = 'Blocked'


Natural Language Query: "What's the NXDOMAIN rate by region?"

Translates to: SELECT cloud_region, AVG(CASE WHEN response_code = 'NXDOMAIN' THEN 1.0 ELSE 0.0 END) FROM dns_event GROUP BY cloud_region
