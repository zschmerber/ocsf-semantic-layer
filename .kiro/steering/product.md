# Product Overview

## Description

OCSF Semantic Layer - A semantic abstraction layer for the Open Cybersecurity Schema Framework (OCSF) that bridges physical schema and business-level security concepts, with visual representation of layer interchange and vector-based intelligent mapping assistance.

## Key Features

- Semantic entity definitions on top of OCSF event classes
- Visual representation of semantic ↔ physical layer interchange
- Vector embeddings for AI-assisted field mapping
- Observable analysis and hot path analytics for threat intelligence
- Warehouse artifact generation (dbt, Cube.js, SQL views)
- Query translation from semantic terms to OCSF-based SQL

## Target Users

- Security data engineers mapping data to OCSF
- Security analysts querying OCSF data using business terms
- Threat intelligence teams running high-speed analytics
- Data architects designing security data warehouses
